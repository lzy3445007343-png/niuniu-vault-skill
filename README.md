# 纽纽知识库整理 Skill（Obsidian）

一句话：帮你把 Obsidian 库整理成**人和 AI 都能用**的结构，还能持续迭代。

- 你往库里放东西有规矩，AI 帮你整理、迭代
- 判断权在你：AI 只动位置，不碰内容，一批一确认
- 库的本体是纯 .md 文件——哪天不用 Obsidian 了，库还在

## 三步上手

1. 把整个文件夹保存到你的电脑
2. 把 `0_开始_把这个文件发给你的AI.md` 这份文件发给你的 AI 助手（WorkBuddy / Claude 等能读文档的 AI 都行），它会判断你的情况、一步步带你搭库
3. 不想用 AI 的，直接看 `skill包/使用说明.md` 自己动手也行

## 里面有什么

```
├── 0_开始_把这个文件发给你的AI.md   ← 买家入口，先发这个
└── skill包/
    ├── SKILL.md                    ← 给 Agent 看的总纲
    ├── 使用说明.md                 ← 人看的快速上手
    ├── assets/                     ← 目录模板 / AGENTS.md / hot.md
    ├── references/                 ← 结构规范 / 搭库七步 / 日常整理五动作 / Agent接入三档
    └── scripts/                    ← check_links / gen_index / scan_old 三个脚本
```

## 设计思路（三条底线）

1. **分类从你库里实际有的内容长出来**，不套现成模板
2. **AI 只动位置、不碰内容**——一个字都不改你的笔记
3. **一次只动一批**，每批给清单，你点头了才往下
