# 脚本使用说明（给 Agent 看的）

本目录下的三个 `.py` 脚本是「库体检 + 自动索引」工具，**标准库即可运行，无需 pip 安装任何包**。

你（Agent）在帮用户整理知识库时，库变大（几十篇以上）后，手动维护目录、查断链会很累——
直接用下面的命令让脚本替你干活，把结果读回来告诉用户即可。

---

## 1. 自动生成目录 `gen_index.py`

**做什么**：在库根生成 `00_总目录.md`（只到分类级），在每个子目录生成 `00_目录.md`（只列直接子项，递归每一层）。
每篇摘要取自首行 `> 一句话：…`；分类 / 文件夹描述取自各自的 `00_导航.md`。

> 关于 `00_导航.md`：**可选项，不建也完全能跑**（描述留空、脚本自动跳过，不会报错）。它是人工写的「这一节是干嘛的 / 什么时候看 / 入口」小导航，格式参考：`> 这一节是干嘛的：…` ＋ `> 什么时候看：…`。脚本只在它存在时才在目录里给它加「先看这个」入口，不存在就不会生成指向它的链接。

**怎么跑**（把路径换成用户的 vault 根目录）：

```
python gen_index.py "用户的vault路径"
```

不传路径则扫描你当前所在目录。

**注意**：
- 只覆盖带「本文件由脚本生成」标记的文件；用户自己手写的目录不会被动。
- 新文件记得提醒用户：开头写一行 `> 一句话：…`，重跑脚本才会被收进目录。

---

## 2. 查断链 `check_links.py`

**做什么**：扫出双链 `[[X]]`、md 链接 `[文字](路径)`、图片附件、反引号里的路径 `x.md` 里**指向不存在目标**的引用。

**怎么跑**：

```
python check_links.py "用户的vault路径"
python check_links.py "用户的vault路径" --wide   # 同时识别跨库引用（引用了 vault 之外的笔记）
```

跑完把「断链清单」读回来，逐条告诉用户哪个文件引用了什么、为什么断，让用户决定修还是删。

---

## 3. 库体检 `scan_old.py`

**做什么**：找出「旧版 / 重复 / 极短 / 散文件」五类：
1. 名字或路径带「旧 / 备份 / 归档」标记的文件
2. 同名文件（出现在不同目录，容易内容分叉）
3. 内容疑似重复（正文开头 300 字完全相同）
4. 极短文件（< 300 字节，可能是占位或残留）
5. 顶层散文件（没归入任何子目录的 md；**库级约定文件 AGENTS.md / hot.md / 00_总目录.md 等不算散文件**，脚本已自动排除）

**怎么跑**：

```
python scan_old.py "用户的vault路径"
```

跑完把清单读回来，建议用户：旧版进 `_旧版/` 口子、重复合并、极短文件确认是否占位、散文件归位。

---

## 运行环境提示

- 需要 Python 3.8+。如果用户本地没有 Python，你（Agent）自己有运行环境就由你来跑，把结果反馈给用户即可——用户不需要会配环境。
- 路径含空格时务必用引号包住。
- 三个脚本都**只读取 + 生成新文件**，不会删除用户任何笔记；库体检脚本更是纯清单、零改动。
