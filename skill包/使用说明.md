# Obsidian 知识库整理 Skill · 使用说明

> 你拿到的是一套「人和 Agent 都能用」的 Obsidian 知识库整理方法。不用自己学——把本文件夹交给你的 Agent，它一读就知道怎么帮你整理、迭代知识库，你和 Agent 一起更新都方便。

## 3 分钟上手

1. 把本文件夹里的 `assets/AGENTS.md` 复制到你 Obsidian vault 的**根目录**（改名为 `AGENTS.md` 或 `CLAUDE.md`，按你用的 Agent 叫法），并把里面的结构改成你自己的。
2. 把本 Skill 的 `SKILL.md` 和 `references/`、`assets/` 交给你的 Agent（直接贴给它能读文件的 Agent，或放进它的 skill 目录）。
3. 对它说一句：「按这个整理我的知识库」即可。

## 日常怎么用（人看）

- **放东西**：直接丢给 Agent，它有规矩——自己的判断和别人的资料分开、放之前先查重、不重复建文件。
- **找东西**：点 `00_目录` 一层层跳到自己想要的位置；库大了让 Agent 帮你搜。
- **迭代**：让 Agent 辅助升级内容，旧版自动留底（走旧版口子），随时能查回来。
- **换 Agent / 隔天接着干**：Agent 读库根 `hot.md` 就能接上之前的进度，不用你重新交代背景。

## Agent 怎么干（Agent 看，核心）

读 `SKILL.md` 即可，里面是完整工作流：
- 接入：先放 `AGENTS.md` 地图
- 搭库：七步流程
- **接手已有库：先只读摸底、出带理由的归类方案，你点头后一批一批整理，笔记内容零改动**
- 整理：日常五动作（三问 / 查重 / 一句话头 / 旧版口子 / 库体检）
- 热缓存：会话结尾写 `hot.md`，跨会话接手
- 接入三档：直接读 → MCP → RAG，按库规模叠加

## 模板在哪

- `assets/AGENTS.md` —— 库根地图模板，直接复制
- `assets/00_目录模板.md` —— 每层目录页模板
- `assets/hot.md` —— 热缓存模板

## 常见问题

- **换工具断片了？** 看库根 `hot.md`，进度都在那。
- **库乱了 / 找不到东西？** 让 Agent 跑「库体检三连」（断链 / 孤儿页 / 过时）。
- **已经有一堆旧笔记了？** 能接手——Agent 先扫一遍出归类方案（每个动作带理由），你点头才动手，一次动一批，笔记内容不会被改。
- **不会用？** 找我，拍下后使用有问题也可以问，不会用可以教。
