# 本知识库地图（给 Agent 看）

> 这是写给 Agent 的「结构地图 + 纪律」。放在 vault 根目录，Agent 进来先读这份就不会迷路。

## 结构
- `写作方法/`：这套库的主线，写作相关的方法论与素材
  - `选题/`：选题方法
  - `排版/`：排版规范
- `项目/`：正在推进的事
- `素材库/`：收集来的素材（别人的资料，和自己的判断分开）

## 命名约定
- 每层目录放一份 `00_目录.md` 当索引（只列本层直接子项）
- 笔记头部建议有 frontmatter（title / tags / created / type / status / summary）
- 每篇第一行写 `> 一句话：讲什么 + 什么时候看`

## Agent 纪律
- 回答问题前，先搜 vault 再答，不要只凭自己记忆
- 改文件前先读、用增量 Edit，不整篇重写
- 涉及个人文件夹（Desktop / Downloads 等）只读不写，除非被明确要求
- 结论升级时走「旧版口子」：旧内容剪切进 `_旧版/`，原处留 ⛔ 取代标记，不删本体
- 每次会话结尾把进度写进库根 `hot.md`（500 字内，覆盖式更新）
