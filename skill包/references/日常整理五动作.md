# 日常整理五动作（库搭好之后每天真实怎么用）

> 写给两个读者：**你**（照着养成习惯）和 **AI**（知道为什么，才不会机械执行走样）。

## 总观念：库是资产，不是记忆

- **不做定期整理。** 触发动作只有两种：① 你自己让记；② AI 觉得很重要（但必须先走完动作二的三步检查才能动手）。
- 库是**需要时才去读的资产**——只要入库时摆对了位，平时根本不用管它。

## 动作一 · 放进去之前，先过三问

| 这东西是什么 | 放哪 |
|---|---|
| 我的判断 / 实操 / 踩坑 / 结论 | ✅ 对应主题文件夹 |
| 别人的资料（竞品、拆解、别人的方法） | ✅ 对应的**资料区**——和自己的思路分开，各放各的 |
| 纯粹「刷到了觉得不错」 | ❌ 别塞 |

收不收看「以后还会再翻吗」；收了之后，自己的归自己、别人的归别人——两边各自能长。

## 动作二 · 放之前，先索引库（三步查重）

1. 读根目录 `00_总目录.md` —— 看这个库有哪些分类
2. 读目标分类的 `00_目录.md` —— 看这一类里已经有什么
3. 查重：**有同样的 → 改原来那篇，不新建**；没有 → 新建（第一行写「一句话」，见动作三）

> 🤖 **给 AI**：这条对你同样有效。你决定「这个值得记」时，先走完三步再动手，别上来就新建文件。

## 动作三 · 每篇第一行写「一句话」

```markdown
> 一句话：{这篇讲什么，一句话说完}——{什么时候看}
```

只写「讲了什么」不够，**要带上「什么时候看」**。

**为什么对 AI 最关键**：有这行，AI 扫一眼目录就知道该不该打开；没有，库一大只能逐个打开、读不动。对人：最痛的不是没学到，是需要的那一刻找不到。

## 动作四 · 更新内容：旧版走口子，不删除任何东西

结论会升级。换下来的旧内容**别急着删**——旧版里可能有新版没写到的东西（完整操作被压成速查、具体案例/价格被压缩、明细表被压成一行）。

**三步操作**：
1. **剪切**：旧内容 → `_旧版/{项目}/{原笔记名}_旧版_{日期}.md`（按项目分一级文件夹，有哪个建哪个，不建空的）
2. **更新**：原处写上新内容
3. **留口子**：新内容正下方写一行跳转（注意路径里有项目文件夹一层，照抄示例别漏）：
   ```markdown
   > ⤵ **旧版（YYYY-MM-DD 前）**：[xxx_旧版_20260922](_旧版/项目名/xxx_旧版_20260922.md)
   ```

有重复时走同一条纪律：**改原来那篇**，在旧处标一行 `⛔ 已被 [[新笔记]] 取代（日期）`。取代链要指向现行文件——指到另一个旧版上 = 链进坑里。

## 动作五 · 库体检三连：断链、孤儿页、过时

搬完文件必跑，平时一月一次。对 AI 说一句话：

> 「给这个库做体检：① 扫所有 md，列出指到不存在文件的路径；② 列出孤儿页（没有任何笔记链接到它、也不在任何 00_目录里的文件）；③ 顺着 `⛔ 已被 [[新笔记]] 取代` 标记，列出还在被人引用的旧版内容。」

| 查什么 | 治什么病 | 为什么肉眼看不出 |
|---|---|---|
| 断链 | 指到不存在文件的路径 | 反引号路径挪动不会自动更新，静默失效，只有扫才暴露 |
| 孤儿页 | 没入口的孤岛文件 | 写了白写，永远检索不出来 |
| 过时 | 已被取代却还在被引用的旧版 | 动作四是埋钩子，这里是收网，配套 |

处理原则不变：**旧版文件本体不删**，只清引用、补口子；孤儿页先判断「该不该有入口」——该有的补进 00_目录 或补链接，真没用的再归档。

## 三条贯穿纪律

1. **结论与证据分开**——原始调研 / 素材只增不改。
2. **够杂了才拆**——同一文件夹平铺超 8 个文件 / 展开要滚动，才建子文件夹。
3. **新规则只管新增**——改了规矩从下一篇执行，存量不批量迁移（移动必断引用，代价大于收益）。

## 双链：什么时候用

`[[笔记名]]` 适合卡片之间互相引用——在 A 里写 `[[B]]`，B 的反向链接会自动显示「谁链了我」。跨文件夹引用写标准路径链接（`[文字](路径.md)`）。
